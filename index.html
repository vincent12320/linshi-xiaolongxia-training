林氏小龙虾
怎么用，以及怎么把干法存下来

豆包能陪你聊，但排版、出图、做文件还得自己来。小龙虾能把这些活干完交给你，也能把一套干法保存下来给全组用。今天讲清楚怎么用它，重点讲怎么保存干法。

基于 Claude Agent SDK 内部二次开发 🎯 三块内容：认识它 · 怎么用 · Skill 🖥 现场配合软件实操演示
2.1
认识它 · 概念

林氏小龙虾是什么

先用一分钟，把这个工具讲清楚。

一句话定义
公司自己开发的 AI 工作平台。你把活交给它，它操作电脑把活干完，产出直接给你文件。
底层是 Claude Agent SDK——一套让 AI 能操作电脑的工具箱。有了它，AI 不再只会对话，而是能打开文件、写文档、点浏览器。公司在这套工具箱上做了二次开发，接进林氏自己的系统和数据，就成了小龙虾。
读写文件

读工作区里的图和文档，产出 Word、PPT、Excel、图片

操作浏览器

自己打开网页、查资料、抓取内容

连内部系统

连钉钉收发消息，查林氏内部知识库

定时执行

设好之后每天自动跑，比如早上9点生成日报

把干法存下来Skill

一套做法存成技能，下次一句话调用，也能分享给同事装上直接用——今天的重点

它不能做什么：

不替你做判断和拍板；数字、价格、竞品信息可能写错，发出去前要人工核；没在「连接器」里授权过的系统读不到；工作区之外的文件看不到。

2.2
认识它 · 效果对比

和豆包比，差别在哪

写文案、生成一个 Word，豆包也能做。小龙虾真正不一样的是另外两件事，后面两章分别讲。

同一条指令

"根据工作区里的3张布艺沙发白底图和《卖点文档》，写2篇小红书种草笔记，突出小户型友好，汇总成一个Word给我。"

豆包需要你先喂料
读不到本地文件夹 连不了钉钉/内部知识库 干法存不下来 Word 能生成
素材要一个个手动上传，做完这次就结束了。下次从头再来一遍。
林氏小龙虾自己取料，干法能留下
直接读工作区文件夹 能连钉钉/内部知识库 干法存成技能，可分享 Word 能生成
素材它自己去工作区取；做完这次，这套做法还能存成技能，下次一句话调用。

素材放进哪里它才看得见，怎么让它接内部系统。→ 第 3 章

2.3
基本功能 · 界面地图

界面地图：8个入口

左边一列是全部入口。日常最常用的是两个：新建任务、技能。

主界面：左侧导航，中间任务区，底部输入框用来派活。

新建任务

每派一个活开一个任务。例：帮我把这10张产品图统一改成白底。

助理

轻量问答入口，快问快答用它，和豆包的用法接近。

灵感

官方案例库，现成的案例可以改成自己的。

自动化

定时任务。例：每天早上9点自动生成AI行业热点日报，发到项目群。

技能

它会哪些活的清单，今天的重点。当前已装31个。

连接器

连接外部系统，比如钉钉、企业微信。连上之后它才能读群消息、发内容。

项目

把它拉进一个项目群，组里多人一起给它派活。例：AI日报群。

历史任务

干过的活都在这里，可以随时回看、接着改，关掉软件也不丢。

2.4
基本功能 · 宝藏入口

宝藏入口：技能超市

像应用商店，点安装即用

技能超市：可搜索、按分类筛选、看安装量，点「安装」即用。

和营销组相关的几个：小红书笔记生成商品主视频一键生成林氏企业内知识搜索网页访问工具

3.1
标准操作流程 · 总览

派活四步走

派活的顺序，和给新同事交接工作一样：在哪儿干、干什么、用什么工具，最后验收。

STEP 1选工作区指定它干活的"桌面"
STEP 2下指令说清目标、素材、产出
STEP 3调技能多数时候它自己会挑
STEP 4看结果验收、追改、下载
需要改的习惯：用豆包是问答，一句话就够。用小龙虾是交接工作，指令里多花30秒把活说清楚，返工会少很多。
3.2
标准操作流程 · 第一步

第一步：选工作区

工作区就是电脑上的一个文件夹。素材放进去它才看得见，干完的活也落在这个文件夹里。工作区之外的文件它读不到。

STEP 1选工作区你在这里
STEP 2下指令
STEP 3调技能
STEP 4看结果

输入框左下角「源码」处切换工作区文件夹；旁边还有「引用」「附件」「技能」三个常用按钮。

A
建一个专属文件夹

例如 D:\小龙虾工作区\小红书投放，把产品图、卖点文档丢进去。

B
在「源码」处选中它

选完之后，这个任务里它读写的都是这个文件夹。

C
临时补素材用「附件」

一两个零散文件不想放文件夹？直接拖进输入框，或点附件上传。

3.3
标准操作流程 · 第二步

第二步：下指令，说全三件事

不用学专门的写法，按钉钉上派活的方式说就行。一条能用的指令包含三件事：目标、素材、产出形式。

STEP 1选工作区
STEP 2下指令你在这里
STEP 3调技能
STEP 4看结果
❌ 说得太少 "帮我写个小红书"

目标模糊，没给素材，也没说要几篇、什么格式。它只能自己编一篇，大概率不能用。
✅ 三件事都说清 "根据工作区里的3张布艺沙发白底图和《卖点文档.docx》，写2篇小红书种草笔记：标题不超过20字，正文150字以内突出'小户型友好'，各配5个话题标签，汇总成一个Word给我。"

三件事拆开看

🎯 目标

写什么、给谁看、突出什么卖点。

📦 素材

用工作区里的哪些文件？点名说。

📄 产出形式

几篇？多长？Word还是表格还是图？

3.4
标准操作流程 · 第三、四步

第三步：调技能；第四步：验收

STEP 1选工作区
STEP 2下指令
STEP 3调技能你在这里
STEP 4看结果和这里

技能怎么被调用

常见自动触发

你说"帮我做个PPT"，它会自己用 HTMLPPT 技能；说"生成一张海报图"，它会调图片生成技能。这一步一般不用你操心。

进阶手动指定

输入框点「技能」按钮，明确指定用哪个——当你确定要某个技能的固定套路时用。

第四步：验收

1
它会边干边汇报

任务要跑几分钟，界面上能看到它每一步在做什么。这是正常的执行过程，不是卡住了。

2
产出是文件，可预览可下载

Word、PPT、图片直接点开看。

3
不满意就追一句

直接说"第二篇标题换个角度，再活泼点"，不用重新派活。左侧任务上的"3轮/14轮"就是来回沟通的次数。

3.5
标准操作流程 · 避坑

五个常见误区

1
把它当搜索引擎/豆包用

一句话就能答的问题，豆包更快。小龙虾适合有产出物的活：要文件、要图、要报告的。

2
空口派活，不给素材

只说"帮我写618复盘"、数据一个没给，它只能编。素材先放进工作区，这一步不能省。

3
以为卡了，中途关掉

复杂任务跑几分钟是正常的，它在操作浏览器、写文件。过程日志还在滚动就说明在执行中。

4
产出不检查直接外发

数字、日期、价格、竞品信息要人工核一遍。它会把错的信息写得很像真的，最后责任在发出去的人。

5
一条指令塞十件事

"写笔记+做海报+排期表+竞品分析"一次全要，容易做乱。大活拆成几轮，一轮一验收。

4.1
今日重点 · Skill

Skill 是什么（说明书 + 工具箱 + 材料箱）

组里有各种SOP文档，投放SOP、素材命名规范。Skill 也是一份SOP，区别是它不给人看，是存进小龙虾里、由它自己照着执行的。

普通对话派活沉淀成 Skill 之后
要求怎么传达每次都要把格式、口吻、注意事项从头讲一遍讲一次，永久生效
质量稳不稳看当天指令写得好不好，时好时坏套路固定，产出格式次次一致
别人能不能用写得好的指令存在你自己的聊天记录里一键分享，同事装上就有同款产出
相当于每周口头教一遍写成SOP，照着做
什么时候用

触发条件：用户说到"周报""weekly"就启动我。

怎么干

做事步骤：先归类、再提炼数据、按模板排版……

交什么

输出格式：一份固定版式的HTML周报文件。

什么样的活值得沉淀：同时满足两个条件——每周或每月都要干一遍，且每次的要求都差不多。周报符合这两条，下面用它来演示。
4.2
现场演示 · 第一幕（切到小龙虾实操）

第一幕：先手工做一次周报

素材是一份"上周工作流水账"（见配套素材文件），当场粘贴，看它输出一份排版好的HTML周报。

提词卡 · 指令①（首次任务）DEMO SCRIPT 1/3
下面是我上周的工作流水账。帮我整理成一份HTML格式的个人周报：
1. 按「本周完成 / 数据亮点 / 问题与风险 / 下周计划」四个板块归类；
2. 数据用醒目的大数字卡片展示；
3. 风格简洁明快，适合直接发钉钉群；
4. 落款写姓名和周数。

【素材粘贴处】↓
（粘贴配套文件里的"素材A·上周工作流水账"）

讲解口径："这条指令里三件事都说了：目标是周报，素材是流水账，产出形式是HTML、四个板块。"

下一幕：这四条要求，下周一还得再打一遍，每周如此。第二幕就是来解决它。
4.3
现场演示 · 第二、三幕

第二幕：沉淀成 Skill；第三幕：复用验证

提词卡 · 指令②（沉淀）DEMO SCRIPT 2/3
刚才生成周报的这套做法很好。请把它沉淀成一个可复用的技能：
- 技能名称：营销周报生成器（weekly-report）
- 触发场景：当我说"生成周报"并粘贴工作流水账时；
- 固定沿用刚才的四板块结构、数字卡片和整体风格。
完成后告诉我怎么调用。

讲解口径："没写代码，一句话就把刚才的做法保存下来了。"说完切到左侧「技能」页，让大家看到列表里多了这个技能。

提词卡 · 指令③（复用验证）DEMO SCRIPT 3/3
生成周报。
【素材粘贴处】↓
（新建一个任务，粘贴配套文件里的"素材B·本周工作流水账"）

讲解口径："这次只说了四个字，四板块、数字卡片、风格都自动带出来了，因为这些要求已经存在技能里。"

素材来源：这次演示的输入都是本地粘贴的文本，没有自动抓取内部系统数据。要接钉钉等系统的数据，得先在「连接器」里配置授权，属于进阶用法。
4.4
Skill · 管理与分享

Skill 怎么保存、怎么分给同事

「技能」页：每个技能都有版本号，可随时停用/删除；右上角「本地安装」用于导入同事分享的技能包。

通道一点对点分享

把技能包发给同事，对方在技能页点「本地安装」导入，和发一份文件差不多。

通道二上架技能超市

用得比较成熟的技能可以上架超市，全公司都能搜索安装。技能超市里的"小红书笔记生成"就是这么来的，目前51次安装。

沉淀的意义：一个人摸索出的做法，存成技能之后组里其他人装上就能得到同样的产出，不用各自再试一遍。
5
收尾

今日总结

1
它是干活工具，产出是文件

要文件、要图、要报告的活交给它；一句话能答完的问题用豆包更快。

2
派活四步：选工作区 → 下指令 → 调技能 → 看结果

素材先放进工作区，技能一般它自己会调，产出不满意就接着追改。

3
一条能用的指令 = 目标 + 素材 + 产出形式

说人话就行，但这三件事要说全。

4
每周重复、要求又差不多的活，可以存成 Skill

一句话就能沉淀，不用写代码；存好之后下次一句话调用。

5
Skill 能分享，也能从技能超市装

点对点发技能包让同事「本地安装」，或者上架技能超市给全公司用。
